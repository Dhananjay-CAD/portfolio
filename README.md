## 📐 About

This portfolio turns a UI design into a fully functional, **semantic HTML** web page for showcasing product development and design engineering work — 🏥 medical devices, 📡 IoT hardware, 🤖 robotics, 🏠 consumer appliances, and 🏭 industrial machinery.

It's built around **real project data** — 🔧 DFM reviews, 🧰 tooling sign-offs, 📊 FEA/CFD studies, and 🌊 mould-flow simulations — not placeholder content. So the structure doubles as a case-study format for engineering deliverables.

---

## 🧭 Sections

| Section | What it covers |
|---|---|
| 👤 **About** | Background, core toolset (SolidWorks CSWP, Fusion 360, FEA/CFD, GD&T, DFM/DFMA), certifications |
| 💼 **Projects** | Filterable case studies — 🏷️ `Product` `Robotics` `Medical` — with process tags & metrics |
| 📈 **Experience** | Career timeline with quantified impact (precision %, cost cuts, cycle-time gains) |
| ⚙️ **Skills** | CAD & Simulation · Manufacturing · Engineering Methods · Software & Data |
| 📬 **Contact** | Email, phone, LinkedIn — open to roles, freelance, and R&D consulting |

---

## ✨ Features

- 📱 **Fully responsive** — desktop, tablet, and mobile
- ♿ **Semantic & accessible** HTML (great for SEO + screen readers)
- 🗂️ **Filterable project grid** — All / Product / Robotics / Medical
- 📊 **Metric-driven project cards** — tolerances, cycle counts, cost/time reductions at a glance
- 🕒 **Timeline-based experience** section for career storytelling
- 🏅 **Skill-level tags** — `Expert` `Advanced` `Proficient` `Certified` instead of generic bars
- 🎨 Clean, minimal, engineering-portfolio-first design

## 🚀 Getting Started

```bash
# 1️⃣ Clone the repo
git clone https://github.com/dhananjay-cad/portfolio.git
cd portfolio
```

Open `index.html` directly in your browser 🖱️, or serve it locally:

```bash
# 🐍 Using Python
python -m http.server 8000

# 📦 Using Node
npx serve
```

🔗 Then visit → `http://localhost:8000`
